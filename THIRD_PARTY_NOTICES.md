# Componentes de terceiros

O app inclui ou usa estes componentes. Cada um mantém a própria licença.

| Componente | Uso | Licença |
|---|---|---|
| [Slint](https://slint.dev) | Interface gráfica | Slint Royalty-free Desktop, Mobile, and Web Applications License 2.0 |
| [btleplug](https://github.com/deviceplug/btleplug) | Bluetooth Low Energy | BSD-3-Clause, MIT ou Apache-2.0 |
| [tokio](https://tokio.rs) | Execução assíncrona | MIT |
| [dbus-rs](https://github.com/diwic/dbus-rs) | D-Bus (BlueZ) no Linux | MIT ou Apache-2.0 |
| libdbus (incluída no build) | Biblioteca D-Bus usada pelo dbus-rs | AFL-2.1 ou GPL-2.0-or-later; o app usa sob AFL-2.1 |
| [ksni](https://github.com/iovxw/ksni) | Ícone na bandeja no Linux | Unlicense |
| [tray-icon](https://github.com/tauri-apps/tray-icon) | Ícone na bandeja no Windows | MIT ou Apache-2.0 |
| [clap](https://github.com/clap-rs/clap) | Linha de comando | MIT ou Apache-2.0 |
| [winit](https://github.com/rust-windowing/winit) | Janela e eventos | Apache-2.0 |
| [Inter](https://rsms.me/inter/) | Fontes da interface | SIL Open Font License 1.1 |
| [Lucide](https://lucide.dev) | Geometria dos ícones | ISC |

A lista completa das crates Rust está em `Cargo.lock`.
