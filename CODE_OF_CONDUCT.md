# Código de conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

## Resumo

- Trate todas as pessoas com respeito.
- Aceite críticas ao código sem levar para o lado pessoal, e critique o código, não a pessoa.
- Não publique dados privados de outra pessoa.
- Não use linguagem ou imagens de teor sexual, ofensas, assédio ou ataques pessoais.

## Aplicação

Relate um comportamento inadequado ao mantenedor, pelo perfil [@pedrohrqe](https://github.com/pedrohrqe) ou por um [relato privado](https://github.com/pedrohrqe/melobuds/security/advisories/new). O mantenedor analisa cada relato e mantém a identidade de quem relatou em sigilo.

O mantenedor pode editar ou remover comentários, commits, issues e pull requests que não seguem este código. Ele também pode bloquear quem repete o comportamento.
